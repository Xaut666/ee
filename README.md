# AI软件赛道-物流-不吃香菜
一、项目简介
一句话说清： 本项目为农业/智慧种植领域的大棚种植户与园区管理员，解决温室环境实时监测、设备自动控制、气象灾害预警、病虫害生态防治以及农产品农残安全溯源的一站式数字孪生管理问题。

二、技术栈
前端：

核心：HTML5 / CSS3 / 原生 JavaScript (ES6+)

渲染：HTML5 Canvas 2D API（用于 3D 数字孪生场景、雷达图、趋势图、粒子系统绘制）

图表：自研轻量级 Canvas 图表内核（代码中重写了 window.echarts，仅支持柱状图/折线图，完全替代 ECharts 实现零依赖）

音频：Web Audio API（用于环境音效模拟）

后端：

无独立后端。当前版本为纯前端仿真演示，所有数据通过前端算法实时生成。

预留接口：实际生产环境需对接 WebSocket / MQTT 协议获取实时传感器数据及下发控制指令（代码中有明确的接入说明）。

AI/大模型：

未接入实际大模型。项目中的“AI生成建议”、“AI识别框”等均为前端规则引擎与 Canvas 动画模拟。

预留了 API 扩展接口，可通过对接大模型（如通义千问、文心一言等）实现真实的农事建议生成与病虫害图像识别。

三、快速开始
环境要求
现代浏览器（Chrome / Edge / Safari 等），需支持 HTML5 Canvas、ES6 语法及 Web Audio API。

无需安装 Node.js 或 Python 环境。

安装步骤
将 greenhouse-monitor3(5).html 文件保存至本地任意文件夹。

确保网络畅通（部分字体或图标可能依赖系统默认，无外部 CDN 依赖）。

运行方式
方式一：直接双击 HTML 文件，使用浏览器打开即可运行。

方式二：使用本地服务器（如 Live Server、http-server）打开，体验更佳。

调试参数：支持 URL Hash 传参，如 #page=monitor（直接进入大棚监测页）、#gh=1（选中1号棚）、#hour=13（锁定演示时间）、#wx=snow（模拟下雪天气）。

四、核心功能
逐条列出已实现的功能及对应的文件/模块（均在单一 HTML 文件内的对应 <script> 模块中）：

园区俯瞰与数字孪生（drawAerial, drawGhTop 模块）：园区全景俯视图、大棚状态呼吸高亮、天气物理反馈（棚膜遮挡降水、积雪堆积、风致晃动）。

大棚环境监测与设备控制（buildSensors, drawDevices, buildTargets 模块）：8项环境指标实时曲线、6台设备（风机、湿帘、滴灌、补光、遮阳、加温）手动/自动控制、目标环境滑杆调节。

高仿真环境气象系统（WX_KINDS, drawSkyline, drawPrecip3, drawFilm3 模块）：12种天气模拟（晴、雨、雪、雾、霾、雷暴等）、24小时气象趋势、7天预报、风场罗盘与气压。

智能水肥与灌溉管理（renderIrr, drawAerial('irr') 模块）：灌溉管网数字孪生、阀门状态、水肥配比（EC/pH）、灌溉计划与调度建议。

病虫害生态防治控制中心（renderPest, pestTick, drawBioSwarm 模块）：虫害预警雷达、天敌投放策略推荐、一键投放天敌（瓢虫、赤眼蜂等）、杀虫灯物理诱杀联动。

灾害防控与安全防护中心（renderSafety, sfTick, drawSafetyMarks 模块）：周界入侵、火灾、地震、野生动物干扰的风险雷达预警、安防系统一键布防、应急处置预案联动。

农残安全检测与溯源（getRiskLevel, renderResidue, printCert 模块）：四色风险等级判定（绿/蓝/橙/红）、检测值与国标对比图、历史批次趋势、合格证打印、异常拦截上架。

管理端与异常处理工作台（workbench 模块）：上传检测报告、进入复核流程、数据看板（批次合格率、最近检测记录）、操作日志。

五、大模型使用说明
当前版本未调用任何第三方大模型 API。

项目中的“AI”功能（如：农事建议生成、植株健康度识别、虫害密度预测）均为前端 JavaScript 模拟的规则引擎与 Canvas 动画。

调用方式（预留）：若需接入大模型，可在以下模块进行扩展：

在 renderWeather() 中的农事建议部分，调用 LLM API（如 GPT-4、通义千问），将当前天气数据作为 Prompt 传入，返回自然语言建议。

在 drawCam() 中的 AI 识别框处，通过 WebSocket 推流至后端，调用视觉大模型进行图像识别并返回坐标。

七、测试说明
当前代码中未包含自动化测试脚本，建议采用以下方式进行测试：

如何运行测试：

自动化测试（推荐）：在 tests/ 目录中引入 Jest 或 Vitest，针对纯函数（如 getRiskLevel、getRiskLevel(detectedValue, limitValue, isBanned)）编写断言测试。

手动测试：直接在浏览器中打开 HTML 文件进行交互测试。

测试覆盖场景：

农残风险判定边界测试：输入 检测值=0.5, 限量=0.5（应为红色）；检测值=0.45, 限量=0.5（应为橙色）；检出禁限用药物（应为橙色）；检测值=0.01, 限量=0.5（应为绿色）。
极端天气并发测试：模拟暴雪（#wx=blizzard）+ 大风，检查棚膜积雪厚度、骨架晃动幅度、粒子系统渲染帧率是否稳定在 60fps。
设备联动测试：在自动模式下，将温度目标设为 15°C，观察加温机组是否自动开启；将土壤湿度目标设为 80%，观察滴灌系统是否启动。
全流程业务测试：从农残检测板块发现红色风险 -> 点击“进入复核流程” -> 工作台确认 -> 拦截上架 -> 打印合格证，验证状态流转逻辑。
移动端适配测试：在手机浏览器中竖屏打开，检查是否出现“请将设备横屏查看”的提示遮罩，以及各面板滚动是否流畅。
